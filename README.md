# BodyLog 試作版（Android向けPWA）

## できること
- 食品名検索・グラム数入力によるカロリー/PFC計算
- マイ食品の手動登録
- 朝食/昼食/夕食/間食の記録
- 筋トレの種目・重量・回数・セット・部位の記録
- 体重・体脂肪率・筋肉量・腹囲の記録
- 体重グラフ、JSONバックアップ/復元
- ブラウザ内保存（クラウド送信なし）

## Androidでの使い方
1. ZIPを解凍し、フォルダ内のファイルをWebサーバーに配置します。
2. HTTPSで公開したURLをAndroid Chromeで開きます。
3. Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

※ index.htmlをファイルアプリから直接開く方法では、PWAインストールやオフライン機能が制限されます。

## 注意
- 同梱の食品値は一般的な目安値で、網羅的な食品成分データベースではありません。商品ラベルや公的な食品成分表を優先してください。
- 記録は端末のブラウザ内に保存されます。ブラウザデータ消去・端末故障・端末変更に備え、設定画面からJSONバックアップを定期的に保存してください。
- 本試作版にはアカウント同期、写真判定、医療上の判断機能はありません。
